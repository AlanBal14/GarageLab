# 🚗 GarageLab

GarageLab es una aplicación web para administrar un garaje virtual. Permite registrar vehículos, organizar una colección personal y conservar la información directamente en el navegador.

## 🌐 Sitio web

Puedes probar GarageLab aquí:

https://alanbal14.github.io/GarageLab/

## ✨ Funcionalidades

- Agregar vehículos mediante un formulario.
- Editar vehículos registrados.
- Eliminar vehículos.
- Marcar autos como favoritos.
- Buscar por marca o modelo.
- Filtrar vehículos por tipo.
- Ordenar por marca, año o potencia.
- Mostrar estadísticas del garaje.
- Visualizar el color de cada vehículo.
- Cambiar entre modo claro y oscuro.
- Guardar automáticamente los vehículos.
- Conservar la información después de recargar la página.
- Navegación mediante un menú fijo.
- Diseño adaptable para diferentes tamaños de pantalla.
